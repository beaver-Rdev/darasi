# دراسي — تطبيق تتبّع الدراسة (Flutter)

تطبيق عربي بالكامل (RTL) بخلفية أبيض كريمي وتصميم عملي بسيط.

## المزايا
- مهام بـ Checkbox تفاعلي، والتأشير يغذّي الخريطة الحرارية فوراً.
- خريطة حرارية بنمط GitHub: أبيض (0 مهام) ← أخضر عشبي داكن (يوم مكثف).
- فلاتر في كل الشاشات (المادة / الحالة / النوع / الفترة).
- جدول أسبوعي (يبدأ السبت) للحصص وخطط المذاكرة والاختبارات القادمة.
- مؤقت بومودورو + ساعة إيقاف، ويسجّل الوقت لكل مادة.
- إشعارات محلية: قبل الموعد بـ 10 دقائق، قبل الاختبار بيوم، وعند انتهاء المؤقت.
- خزنة الاختبارات: المادة + الدرجة + الدرجة العظمى (أي رقم) + صورة الورقة.
- مكان مخصص للشعار في الهيدر وشاشة البداية.
- متجاوب: شريط سفلي على الهاتف وشريط جانبي على الشاشات العريضة.

## الحصول على ملف APK بدون تثبيت أي شيء على جهازك

GitHub سيبني التطبيق لك على خوادمه مجاناً.

1. أنشئ حساباً على github.com (إن لم يكن عندك).
2. من الزر **+** أعلى الصفحة اختر **New repository**، اكتب الاسم `darasi`، اضغط **Create repository**.
3. فُكّ ضغط ملف ZIP، وادخل المجلد. يجب أن ترى فيه: `pubspec.yaml` و `lib` و `assets` و `tools` و `.github`.
   - على ماك المجلد `.github` مخفي: اضغط `Cmd + Shift + .` لإظهاره.
4. في صفحة المستودع اضغط **uploading an existing file**، حدّد **كل ما بداخل المجلد** (Ctrl+A) واسحبه إلى الصفحة. انتظر انتهاء الرفع ثم اضغط **Commit changes**.
   - ارفع محتويات المجلد وليس المجلد نفسه، حتى يكون `pubspec.yaml` في الجذر.
   - إن لم يظهر `.github` بعد الرفع: **Add file ← Create new file**، اكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف الموجود في ZIP.
5. افتح تبويب **Actions**. سترى **Build APK** يعمل. انتظر 8 إلى 15 دقيقة حتى تظهر علامة ✔ خضراء.
   - إن لم يبدأ: **Actions ← Build APK ← Run workflow**.
6. حمّل الملف من صفحة المستودع: **Releases ← build-1 ← app-release.apk**.
   - أو من التشغيل نفسه: **Artifacts ← darasi-apk** (ملف zip بداخله الـ APK).
7. افتح رابط التحميل من هاتف Android وثبّت الملف.
   - اسمح للمتصفح بتثبيت التطبيقات عند الطلب.
   - إن ظهر تحذير Play Protect اختر **More details ← Install anyway**.
8. عند أول تشغيل اسمح بالإشعارات.

## إذا ظهرت علامة ✗ حمراء
افتح التشغيل الفاشل، اضغط الخطوة الحمراء، وانسخ آخر 30 إلى 40 سطراً من السجل.

## تغيير الشعار
استبدل `assets/images/logo.png` بشعارك (مربع، الأفضل 512×512) وبنفس الاسم، وارفعه إلى GitHub. سيُبنى APK جديد تلقائياً مع كل رفع.

## البناء على جهازك (اختياري، يحتاج Flutter 3.27)
```bash
flutter create --platforms=android --org com.darasi --project-name darasi /tmp/scaffold
cp -r /tmp/scaffold/android ./android
python3 tools/patch_android.py
flutter pub get
flutter build apk --release
# الناتج: build/app/outputs/flutter-apk/app-release.apk
```

## هيكل المشروع
```
lib/
├── main.dart                 نقطة البداية + إعداد RTL والعربية
├── theme.dart                الألوان والخط (Cairo) والثيم
├── utils.dart                التواريخ والأرقام
├── models.dart               المهمة / جلسة المذاكرة / نتيجة الاختبار
├── state.dart                الحالة + الحفظ المحلي + الاستعلامات
├── timer_controller.dart     منطق المؤقت
├── notifications.dart        الإشعارات المحلية
├── screens/                  splash, shell, home, schedule, timer, exams
└── widgets/                  heatmap, task_tile, add_task_sheet, logo, common
```

## ملاحظات
- الاستهداف الأساسي هو Android. الكود نفسه قابل للتشغيل على iOS (يلزم جهاز Mac) وسطح المكتب. أما الويب فيحتاج تعديلاً بسيطاً في رفع الصور.
- الإشعارات تقريبية التوقيت (قد تتأخر دقائق) لأن Android يوفّر البطارية.
- الخط Cairo يُحمَّل من الإنترنت عند أول تشغيل، وبدونه يُستخدم خط النظام العربي تلقائياً.
- البيانات محفوظة على الجهاز فقط.
